# T15 — Export: PNG postcard + self-contained HTML

**Blocked by:** T05 · **Effort:** small-medium

## Goal
Two share paths, both offline: a screenshot worth posting, and a single HTML
file anyone can open with no install and no server.

## Files
- new: `viewer/src/export.js`
- new: `citygen/export_html.py` · edit: `citygen/cli.py` (`export` subcommand)

## PNG postcard
- Render at 2× device pixel ratio into an offscreen render target, then
  `canvas.toDataURL('image/png')`.
- Compose a caption strip at the bottom on a 2D canvas before download:
  `repo name · N files · N,NNN LOC · N authors · generated by Chronopolis`
  plus the active overlay mode and, if the timeline is not at "now", the
  snapshot date.
- `P` takes the shot; UI chrome is excluded automatically (reuse `H`'s
  hide-UI path).
- Filename: `chronopolis-<repo>-<mode>-<yyyymmdd>.png`.
- Requires `preserveDrawingBuffer: true` on the renderer **or** an explicit
  render immediately before `toDataURL` — prefer the explicit render, since
  `preserveDrawingBuffer` costs performance on every frame.

## Self-contained HTML
```bash
python -m citygen export out/city.json -o chronopolis-reachable.html
```
- The Vite build is produced with `inlineDynamicImports` and a single-file
  plugin-free approach: build normally, then have `export_html.py` inline
  `dist/assets/*.js` and `*.css` into `dist/index.html` textually. Keep the
  built bundle checked in under `viewer/dist-embed/` (or built on demand) so
  the CLI can produce the file without npm being installed on the user's box.
- City JSON is gzipped, base64'd, and injected as
  `<script>window.__CHRONOPOLIS_CITY__="…"</script>` before the bundle. The
  viewer already prefers that global (T05).
- Result must open from `file://` with **zero network requests** — verify in the
  browser network panel. That is a stated hard requirement.
- Target size: < 4 MB for a 1000-file city. Report the size on stdout.

## Also worth 20 lines
`citygen serve out/city.json` — `http.server` on the viewer dist with the city
copied in, opens the browser. Removes the "how do I look at it" friction for
users who never ran a dev server.

## Acceptance criteria
- PNG is crisp at 2×, caption is legible, no UI chrome in frame.
- Exported HTML opens from the filesystem in Chrome and Firefox, renders, and
  makes zero requests.
- Exported HTML for `cve-bin-tool` is under 8 MB and loads in under 3 s.
- `citygen export --help` documents both flags.

## Default if ambiguous
- No animated GIF/WebM export in v1 (encoding is a rabbit hole). If someone
  wants a clip, they screen-record.
- Caption strip is dark with light text, matching the viewer.
